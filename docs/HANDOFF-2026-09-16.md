## 本轮踩过、值得记住的坑

- **`out/` 是运行产物**：改 `src/**` 后必须重建再重启；`electron-vite dev` 的 watcher 本机实测
  **不一定**重建 `out/`（这就是用户以为"改了没用"的原因）。`restart-dev.sh` 已把构建并进去。
- **必须 detached 启动**：`nohup npm run dev &` 仍属调用方进程组，远程 agent 的工具调用被中断时
  整棵树被回收 → 用户看到"MPI 自己定时关掉"。用 `scripts/dev-launch.mjs`（detached + unref）。
- **脚本先构建后杀进程**：中断时最坏是"没重启"，绝不留下"已关掉"。
- **上限要按用户看到的维度设**，别按内部数据结构设（raw vs rendered 就是这个教训）。
- **验证 harness 必须镜像真实 DOM**：之前把 `.thread-view` 直挂 `.app` 绕过了 `.app-main`，
  所以那个 bug 没测出来；现在 headless probe 还会断言 `cssApplied`（曾因 CSS 路径写错导致
  整页无样式，差点读成"布局坏了"）。
- **Git Bash / heredoc 转义坑**（本会话踩了 4 次）：往 JS/文档里写 `\s`、`\n`、`\` 会被吃掉，
  改用 `String.fromCharCode`、`indexOf(fromIndex)`、或直接改文件后人工核对。
